## 项目范围

- 广告数据来自程序生成或用户导入的模拟 CSV，性质为 `simulation`；页面中的金额、订单和收益用于学习指标及诊断。
- `product_events` 记录本地练习操作及自动化自测，性质为 `local_practice`。它可用于检查操作链路及练习事件查询，不能代表真实广告受众行为、真实用户规模或商业转化。
- 当前基础版采用规则诊断、关键词知识卡和本地创意模板。模型兼容接口的代码已提供，真实服务、生成质量和成本需要单独验证。
- 模拟投放结果用于观察参数、指标与假设的关系。真实广告账户、实际预算执行、广告平台归因、真实用户访谈与商业化成果均需要后续独立证据。

## 可考虑的简历表达

完成并能够复现对应操作后，可从以下方向组织三点；按自己的实际参与范围修改措辞：

1. 围绕模拟广告分析场景，梳理用户操作、数据字段和指标口径，构建 CSV 导入、SQLite 存储及可视化报表流程。
2. 实现数据质量校验与操作事件记录，使用 SQL 完成聚合、关联及任务结果分析，结合规则诊断输出异常证据、原因假设和验证建议。
3. 将诊断及知识查询封装为 MCP/Skill 工具，配套创意草稿与模拟实验记录，完成个人自测、异常检查及可复现文档。

可以写具体交付物和方法。没有真实实验记录时，不写增长率、节省时间、投放 ROI 提升、用户量、客户数或商业化收益。模板生成不能表述为已经验证的大模型生成效果；协议测试不能表述为已经完成真实 Agent 自主调用。
